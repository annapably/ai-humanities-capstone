# Layer 3 — RAG

Retrieval-Augmented Generation: your system draws on a collection you have curated, and users can see where answers come from.

## Steps

1. Put your source documents in `data/raw/`.
2. Uncomment the RAG dependencies in `requirements.txt` and run `pip install -r requirements.txt`.
3. Run `python src/03_rag/ingest.py` to chunk and embed your collection.
4. Run `python src/03_rag/query.py` to test retrieval.

## What to record

- How you chunked (size, overlap, strategy)
- Which embedding model you used
- Whether retrieved chunks actually matched what was needed
- Cases where retrieval failed — log these in your failure analysis

## Transparency requirement

Your system must make it clear to users which parts of an answer come from your collection and which are generated by the model. Implement source citations in `query.py`.
