# Layer 4 — Agents (optional)

Only implement this layer if agents genuinely earn their place. From the brief:

> "Agents add cost, unreliability, and risk, so use them only if they earn their place. If you conclude that a simpler design serves your question better, that is a legitimate and valuable finding, provided you explain why."

If you skip this layer, document your reasoning in `milestones/06_showcase_and_documentation/what_i_left_out.md`.

## Human-in-the-loop requirement

State clearly in your documentation:
- What tools the agent may call autonomously
- What it may **not** do without your approval

This is a graded requirement (Ethics and transparency, 10%).
