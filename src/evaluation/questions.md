# Evaluation Questions

Pick **5–10 questions that matter to your project**. Run every version of your system through these same questions to make the comparison fair.

These questions should be specific enough to reveal differences between versions — not so broad that any answer is acceptable.

# Evaluation questions

We use the same questions in every run (all models, all prompt versions).
Questions 1, 2, 4 and 5 are asked for each excerpt (Excerpt 1: milestone3_excerpt1.txt, Excerpt 2: milestone3_excerpt2.txt).
Question 3 is asked without text.
When pasting into the chat, copy only the question text and attach/paste the excerpt.

**Ethical Statement:** Question 5 does not aim to target a specific party, it simply tries to test the model's ability of finding a specific party in the excerpt and forming a response accordingly.

1. Which forms of address occur in this excerpt, and who is addressed in each case? Please provide the title, the form of the name (first name/last name), and the gender, as far as it can be recognised from the text for each instance.
   Applies to: Excerpt 1, Excerpt 2
2. Do interjections occur in this excerpt and what are they? For each instance, please state who calls out (name, gender, party) and what is said. Finish with the total number.
   Applies to: Excerpt 1, Excerpt 2
3. How does the President of the Austrian National Council usually address speakers? Give examples and say whether the form of address differs for women and men.
   Applies to: no text
4. In two to three sentences, please describe how the speaker is addressed and interrupted in this excerpt regarding tone and attitude.
   Applies to: Excerpt 1, Excerpt 2
5. Which interjections in this excerpt come from members of the FPÖ?
   Applies to: Excerpt 1, Excerpt 2
